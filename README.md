# Rewan Khaled Yussuf — AI Engineer Portfolio

A modern, minimalist, editorial portfolio website for **Rewan Khaled Yussuf** — AI Engineer specializing in Machine Learning, Deep Learning, Computer Vision, and AI Automation.

Built with an editorial designer aesthetic: generous whitespace, Epilogue typography, crisp geometric accents (coral quarter-circle, teal rounded square, pink geometric arch, yellow badge), and a clean client-ready presentation.

---

## 🎨 Design System

- **Aesthetic**: Minimalist creative portfolio, editorial layout, large typographic hierarchy
- **Colors**:
  - Dark Charcoal: `#2D2D2D`
  - Pure White: `#FFFFFF`
  - Coral / Red: `#FF6250`
  - Teal / Green: `#009379`
  - Soft Pink: `#FFB5B0`
  - Soft Yellow: `#FFD66B`
  - Light Neutral Grays: `#F5F5F5` / `#F8F8F8`
- **Typography**: [Epilogue](https://fonts.google.com/specimen/Epilogue) (Google Fonts)
- **Buttons**: Dark charcoal rectangular buttons, crisp hover states, accessible focus indicators
